# Reports

Generated output of the test layers lands here (one folder per layer, ignored by Git except this file).
Layout: `unit/`, `component/`, `integration/`, `e2e/`, `native/`, `performance/`, `security/`,
`visual/`, `accessibility/`, `installer/`, `logs/`, `screenshots/`, `videos/`, `traces/`.
`docs/Testing-Strategy.md` explains what each layer proves and what it cannot.
